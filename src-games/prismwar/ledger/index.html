Post this ledger card?

This is the card the game handed over. Posting puts it on the shared wall below for everyone who opens this page. Nothing else is sent — no account, no cookie, no tracking.

Shared, unaudited, and cheerfully unofficial. Anyone with the game can post the ledger card from its Ledger tab. The wall is a live shared list (playhtml) — it is a social signal, not a leaderboard: a card's numbers come from the player's own browser, and the Sig line only tells the game whether that player's save was edited.
